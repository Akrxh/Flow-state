# Flow-state(`keepstudy`)

A lightweight, single-file web dashboard designed for comprehensive academic tracking during the Class XI curriculum. Built with a tactile, matte-paper visual aesthetic, real-time cloud synchronization, and robust progress analytics.

---

## 🌟 Key Features

* **Tactile Matte Paper Aesthetics**: Styled with a sophisticated dark-slate matte finish, subtle tonal borders, and cardstock-inspired surfaces for a distraction-free, premium visual experience.
* **Real-time Cloud Firestore Sync**: Powered by Google Firebase (`keepstudy`), ensuring instant cross-device synchronization of all completed topics and study metrics.
* **Secure Passcode Authentication**: Protected entry workflow requiring a system security passcode to safeguard academic data and ensure private workspace access.
* **Comprehensive Syllabus Matrix**: Structured hierarchical trees covering core Class XI subjects:
  * Physics
  * Chemistry
  * Biology
  * Psychology
  * Computer Science
  * English Core
* **Advanced Analytics & Visualizations**: Interactive data visualization driven by Chart.js, featuring real-time percentage completion doughnut charts and subject-wise breakdown bar graphs.
* **Activity History Stream**: Chronological audit trail logging every completed or modified topic timestamp for productivity monitoring.
* **Single-File Architecture**: Entirely self-contained within a single `index.html` file, making it exceptionally easy to host, deploy, or run locally.

---

## 🛠️ Tech Stack

* **Frontend Framework**: HTML5, Vanilla JavaScript (ES6+ Modules)
* **Styling & Design**: Tailwind CSS (via CDN) with custom CSS variables for matte styling
* **Icons**: Lucide Icons
* **Charts**: Chart.js
* **Backend & Database**: Google Cloud Firebase (Firestore & Analytics)
